Privacy

Last updated October 2026 (GeoPicks 1.7.1).

The app runs on your machine

GeoPicks is a desktop app. Its engine runs on your own Mac or Windows PC and only accepts connections from that computer. Your projects (logs, picks, maps, seismic, grids) and your license key are stored in your own user folder (~/Library/Application Support/GeoPicks on a Mac, %APPDATA%\GeoPicks on Windows) and are never uploaded. License keys are checked on your computer; there is no activation server. The app has no analytics, telemetry or crash reporting.

Starting with GeoPicks 1.7.1, each beta key works on one computer. The Machine ID shown on the Activate screen (it looks like GPM-XXXX-XXXX-XXXX) is a one-way hash of the computer's hardware ID (on Windows, the ID Windows assigns to the installation) that GeoPicks computes on the device. The hardware ID itself never leaves your computer, and the Machine ID can't be turned back into it. The Machine ID is only sent when you choose to send it, on a form on this website or by email, or when the Share feedback button puts it in the feedback link. It is used only to issue a key for that computer.

What the app sends over the network

None of these sends your project files. Each one goes straight from your computer to the service named.

  • Update check (GitHub). At most once a day when GeoPicks starts, and whenever you click Check for updates, it asks GitHub for the latest GeoPicks release. If you click Update now, the installer is downloaded from GitHub. GitHub sees a normal web request (your IP address and the GeoPicks version).
  • Elevation lookup (USGS), only when you click it. The KB editor's ground-level lookup sends the latitude and longitude of the wells you're looking up to the USGS elevation service.
  • Township/range/section grid (BLM), only when you turn it on. The T-R-S overlay sends the bounding box around your located wells to the BLM land-survey (PLSS) service. The result is saved with the project, so it isn't fetched again.
  • Street basemap (OpenStreetMap), only when you choose it. The Streets background loads map tiles from OpenStreetMap, which reveals the area of the map you're viewing. The default Plain background loads nothing.
  • Fonts and map library. Since GeoPicks 1.7.0, the app's typefaces and the Leaflet map library are bundled with the app and are no longer fetched from the internet. (Version 1.6.3 and earlier load the typefaces from Google Fonts and Leaflet from unpkg.com: ordinary web requests with your IP address and no project data.)
  • Beta feedback button. Near the end of a beta key, GeoPicks shows a Share feedback button. Clicking it opens the feedback page on this website in your browser, with the name and email from your license filled in. Since GeoPicks 1.7.1, the link also includes this computer's Machine ID, so the form can fill it in. Nothing is sent until you submit the form.

Links you click (release notes, the download page, email) open in your web browser.

This website

  • No analytics, no tracking scripts, no cookies. The site is plain HTML hosted on GitHub Pages, which, like any web host, receives your IP address when you visit.
  • The beta signup form sends your name, email, company, platform, Machine ID (if you enter one) and notes to Formspree, which emails them to me. I use them to send your beta license key and to follow up about GeoPicks. The Machine ID is used only to issue your key for that computer.
  • The beta feedback form sends your answers, including your Machine ID, to Formspree the same way, which emails them to me. I use them to send your additional 3-month key for that computer and to improve GeoPicks, and I quote you on this website only if you said yes on the form.
  • The download buttons fetch the installer from GitHub.
